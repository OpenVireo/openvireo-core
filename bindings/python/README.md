# openvireo (Python)

The Python binding of [openvireo-core](https://github.com/openvireo/openvireo-core): OpenVireo
accounts, vaults, sync, share links and `.kdbx` files, on the same Rust core as the iOS, desktop and
web apps. The `openvireo._core` module is generated by UniFFI from `bindings/ov-ffi`. `openvireo.hosts`
adds ready-made platform parts (HTTP, secret store, offline cache, clock, logging).

- Python 3.10 or later. One wheel per platform (`py3-none-<platform>`) covers every Python version,
  because the library is loaded through ctypes rather than the CPython ABI.
- Every network or storage call is a coroutine (asyncio).

## Install

Until the package is on PyPI, wheels are attached to the core's GitHub releases:

```sh
pip install openvireo --find-links https://github.com/openvireo/openvireo-core/releases/expanded_assets/<tag>
pip install "openvireo[httpx]"     # optional: async HTTP on httpx (otherwise urllib in a thread)
pip install "openvireo[keyring]"   # optional: keep sessions in the OS keychain
```

## Quickstart

```python
import asyncio
import openvireo as ov
from openvireo.hosts import KeyringStore, default_host


async def main() -> None:
    client = ov.OvClient(
        ov.ClientConfig(device=ov.DeviceInfo(id=None, name="my script", platform=ov.Platform.CLI),
                        offline=False, server=None),
        default_host(store=KeyringStore(), cache_dir="~/.cache/openvireo"),
    )
    account = await client.connect("https://accounts.openvireo.com", ov.CancelToken())
    step = await account.login(
        ov.LoginInput(email="me@example.com", password=b"master password",
                      secret_key=b"A3-...", totp=None, trust_device=True),
        ov.CancelToken(),
    )
    if isinstance(step, ov.LoginStep.NEEDS_TOTP):
        step = await account.submit_totp(step.challenge, input("Code: "), ov.CancelToken())

    for info in await account.vaults(ov.CancelToken()):
        vault = await account.open_vault(info.id, ov.CancelToken())
        for entry in vault.entries(False):
            print(info.name, "/", entry.title, entry.username)


asyncio.run(main())
```

Errors are `ov.OvError` with `code` (`ov.OvErrorCode`), `wire_code`, `message`, `status`,
`retry_after`, `details` and `server_code`:

```python
try:
    ...
except ov.OvError as e:
    if e.code == ov.OvErrorCode.UNAUTHORIZED:
        print("wrong password")
```

## Hosts

`default_host()` picks httpx when it's installed, else urllib; `MemoryStore` and `MemoryCache`
unless you pass `store=` / `cache_dir=`; the system clock; and `logging.getLogger("openvireo")`.
To write your own part, subclass the interface (`ov.HttpTransport`, `ov.SecureStore`,
`ov.BlobCache`, `ov.Clock`, `ov.LogSink`). A transport must not follow redirects or keep cookies,
and must raise `ov.TransportError` (not other exceptions) when there's no response.

Host coroutines run on the event loop that awaits the core call; the core starts no threads of its
own. Secrets that cross into Python (passwords, Secret Keys, stored tokens) are plain `bytes` that
Python can't wipe; the core zeroizes its own copies.

## Develop

```sh
cargo xtask python            # venv (uv if installed), maturin develop, pytest
cargo xtask python --smoke    # + test-server feature and the live tests against the testkit relay
cargo xtask python --wheel    # + a release wheel in <target>/wheels
```

The live tests run the real `UrllibTransport` and `HttpxTransport` against the in-memory auth and
sync servers (`crates/ov-testkit/examples/http_relay.rs`) over loopback HTTP: register, log in,
vaults, entries, sync, share links, error codes and the event stream.
